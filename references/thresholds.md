# 阈值、取值理由与校准

所有阈值集中在三处，改一处必须同步其余：

| 位置 | 内容 |
|---|---|
| `lib/features.py: TH` | 六维归一化用的饱和点 |
| `lib/features.py: WEIGHTS` | 六维合成风险分的权重 |
| `lib/judges.py: CFG` | 三裁判的判定线 |

## 六维饱和点

| 键 | 值 | 含义 | 为什么是这个数 |
|---|---|---|---|
| `cv_full` | 0.55 | 句长变异系数达到此值即「足够不规则」 | 中文说明文段落的 CV 多在 0.25~0.45；学术写作实测中位数约 0.38，取 0.55 作为「明显起伏」的安全上界 |
| `cv_floor` | 0.20 | 低于此值视为强均齐 | 五个句子长度差 < 3 字时 CV 约 0.08~0.15 |
| `mid_len` | (20, 35) | 学术写作甜区句长 | 中文字符计；低于 20 偏口语，高于 35 偏长句 |
| `conn_full` | 0.75 | 每句连接词数饱和点 | 人类学术写作约 0.3~0.5/句，AI 输出常达 0.8~1.2/句 |
| `template_full` | 1.60 | 每百字模板命中饱和点 | 正常学术段落 0~0.8/百字 |
| `value_full` | 2.20 | 每百字信息性记号（数字/引用/书名/缩写）饱和点 | 方法与结果章节约 3~5/百字，绪论约 0.5~1/百字 |
| `bigram_full` | 0.35 | 二元组重复率饱和点 | 120 字段落正常重复率 0.10~0.22 |
| `filler_full` | 0.22 | 抽象名词字占比饱和点 | 套话段落可达 0.25 以上 |
| `start_dup_full` | 0.50 | 句首三字重复率饱和点 | 排比段落才接近 0.5 |

## 维度权重

`a1 0.22 / a2 0.16 / a3 0.22 / a4 0.14 / a5 0.10 / a6 0.16`

理由：a1 与 a3 是检测器最敏感的两类特征（突发性、模板度），权重最高；
a5 的启发式最弱（无分词、无词频表），权重最低，避免它主导排序。

## 风险分级

| 等级 | 阈值 | 处置 |
|---|---|---|
| 高 | ≥ 0.62 | 优先进入本轮任务（≥0.70 时不受单段预算上限约束） |
| 中 | ≥ 0.45 | 预算有余时处理 |
| 低 | < 0.45 | 不改，写进报告即可 |

0.62 的来历：在 12 篇中文学位论文（约 900 段）上做的分位校准，
取「人工判定为明显机器味」样本的 30% 分位。样本量小，**这是一个可调的工作点，不是真理**。

## 三裁判阈值

| 键 | 值 | 含义 |
|---|---|---|
| `min_overlap` | 0.55 | 改写前后字二元组 Dice 下限 |
| `len_ratio` | (0.60, 1.25) | 保真裁判允许的长度比 |
| `max_neg_delta` | 0 | 否定词数量不得变化 |
| `max_quant_delta` | 1 | 量词允许 ±1（合句时的自然漂移） |
| `aigc_threshold` | 0.62 | r = risk / 0.62，用于 minimax 归一化 |
| `repeat_threshold` | 0.35 | 13 字片段跨段重复比例上限 |
| `regression_cap` | 0.15 | 单指标相对原文的最大允许退化 |

改写端还有两道独立闸（`scripts/apply_edits.py`）：
实体多重集必须完全相同；长度比必须在 `[0.55, 1.40]`。
改写闸比裁判闸更宽，因为裁判闸是「比较候选之间」，改写闸是「拦住离谱改动」。

## 重要限制：这些分不是概率

- 风险分是**篇内相对量**。同一段放在两篇不同文档里，分数会变（因为重复项基于篇内指纹）。
- 它没有经过任何检测器的标注校准，**不能**换算成「AIGC 率」「查重率」「通过率」。
- 换基座模型、换学科、换文体（如法学 vs 材料学）都会漂移；跨学科比较无意义。

## 语义保真的现状与替换路径

v0.1 的「Sem」是代理指标：字二元组 Dice + 否定词/量词守恒 + 长度比。
它抓得住删句、改数、掉否定，抓不住「同义改写但意思反了」。

替换路径（按顺序）：

1. 接入句向量模型（如 `text2vec-base-chinese`），对原段与改写段算余弦，阈值 0.85。
2. 保留现有三个信号作为硬闸，向量相似度只做软排序——顺序不能反，
   因为向量模型对「数字被改」不敏感。
3. 若要接近检测器口径，再叠加一个 RoBERTa 分类器做排序信号；
   但**不要**把它当验收标准，它只是又一个代理。

## 校准方法（要做的时候照这个做）

1. 取 30 篇以上真实论文，人工标注每段「像 AI / 不像 AI」。
2. 扫 `cv_full`、`conn_full`、`template_full` 三个饱和点，画出 ROC。
3. 以「高风险段的精确率 ≥ 0.7」为目标取工作点，而不是取 AUC 最大点——
   报告里说「这段危险」的代价，比漏掉一段高。
4. 重新校准后同步更新本文件的表格，否则代码与文档分叉。
